# Derived Reciprocity Moduli Lab

Interactive visualization and coherence sandbox for the **Derived Reciprocity Moduli Principle**.

## Features

- Galois and automorphic “galaxies”
- Interactive local-prime perturbation
- Coherence score and local-data table
- Coordinated quadratic twist using χ₋₄
- Architecture and mathematical-rules panels
- Derived-layer visualization
- Installable Progressive Web App (PWA)
- Offline caching after the first successful load

## Scholarly status

This application is a visualization and research-thinking tool. It is **not a proof** of the Derived Reciprocity Moduli Principle. Established mathematics, conjectural synthesis, and illustrative visual behavior are labeled separately in the app.
